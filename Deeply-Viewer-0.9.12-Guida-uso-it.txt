Deeply Deeply Viewer 0.9.12
Guida all'utilizzo

INSTALLAZIONE
1. Scarica lo ZIP dalla release GitHub ufficiale.
2. Confronta il file .sha256.
3. Verifica il file .minisig con la chiave pubblica del README.
4. Estrai tutto lo ZIP in una cartella dedicata.
5. Avvia Deeply-Viewer.exe.

Non eliminare la cartella assets: il pacchetto e portable.

LINGUA E AGGIORNAMENTI
Imposta DEEPLY_UI_LANGUAGE=it per l'italiano. Usa il controllo aggiornamenti:
l'updater segue il repository community e Deeply-Update-policy.json.

BROWSER
Usa il browser interno per URL HTTP/HTTPS, navigazione, ricaricamento e
apertura nel browser di sistema. Gli schemi javascript: e data: sono rifiutati.

AVATAR
Nei menu contestuali puoi rifiutare separatamente teleport e conference chat.
Le preferenze sono persistenti e il rifiuto conference precede l'apertura.

LOG E FIRESTORM
Attiva la condivisione Firestorm solo se vuoi usare la stessa cartella locale.
Deeply importa transcript esistenti e puo leggere/scrivere nella cartella
compatibile trovata. Non vengono sincronizzati dati via Internet.

GRAFICA E REPORT
La riduzione adattiva protegge il sistema senza modificare profili Custom.
I report possono essere controllati, copiati o inviati tramite bozza GitHub
solo dopo autorizzazione. Log, posizione e screenshot sono opzionali.

SICUREZZA
Un avviso del sistema operativo non va ignorato automaticamente. Controlla
sempre provenienza, SHA-256, Minisign e risultati delle scansioni disponibili.
